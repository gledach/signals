# Signal Chrome Extension

Chrome side-panel extension for the Signal (Competitive Intelligence Agent) platform — full dashboard, AI-powered Intel Check, signal clipper, and desktop notifications.

## Features

### Side Panel (main UI)
Click the extension icon to open a full-height side panel with three tabs:

**Dashboard**
- Total signal count, critical count, last cron run timestamp
- Filter by company, impact band, signal type
- Click any signal to see full detail (summary, rationale, source link)
- Inline reclassify — click the signal type badge to change it (writes to Turso)
- Dismiss to noise — one-click ✕ button

**Intel** (unified Check → Clip flow)
1. Select a competitor from the dropdown
2. Click "Check page against intel" — Chrome AI compares current page content against known signals for that company
3. See what's new vs. what you already know, with impact assessment
4. Optionally save the signal — form is pre-filled by AI (company, type, notes, URL)
5. Click "Save signal to Turso" — writes directly to the signals table

**Settings**
- API URL (Railway, localhost, etc.)
- Poll interval (1–60 minutes)
- Notification threshold (critical / high+ / medium+ / all)
- Chrome AI status display (Summarizer, Prompt API, Rewriter)

### Pre-baked Intel Data
Run `npm run chrome-data` to generate a local snapshot of recent signals per competitor. The Intel Check reads this file instead of calling the API — making comparison instant and offline-capable.

```bash
npm run chrome-data          # last 7 days (default)
npm run chrome-data:14d      # last 14 days
```

Output: `chrome-extension/data/companies.json` (gitignored, regenerate on demand).

Falls back to live API signals if no local file exists.

### Context Menu Clipper
Right-click any page → "Clip to Signal" → auto-fills the Intel tab with URL, title, and selected text.

### Background Polling & Notifications
- Polls Signal API every N minutes (configurable)
- Desktop notifications for signals above your threshold
- Badge count on the extension icon

### Site-Specific Content Extraction
The content script has optimized extractors for:
- **LinkedIn** — posts, articles, company pages (strips ads, nav, messaging)
- **Twitter/X** — tweet text and threads
- **GitHub** — README, issues, PR bodies
- **Generic** — article/main content with nav/footer/aside removed

All pages are limited to 6,000 chars and stripped of images/video/scripts.

## Chrome AI (on-device, zero cost)

All AI features run locally via Gemini Nano — no API calls, no tokens, no privacy concerns.

| Feature | Chrome API | Used For |
|---------|-----------|----------|
| **Summarizer** | `Summarizer.create()` | One-click page summary for clip notes |
| **Prompt API** | `LanguageModel.create()` | Intel Check comparison, signal classification |
| **Rewriter** | `Rewriter.create()` | Polish clip notes (tone: concise/formal) |

**Requirements** (AI features are optional — extension works without them):
- Chrome 138+ (stable)
- 22 GB free disk space (one-time Gemini Nano download)
- Windows 10/11, macOS 13+, or Linux

Check availability in Settings → Chrome AI section.

## Install

1. Open `chrome://extensions/`
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked" → select this `chrome-extension/` folder
4. Click the extension icon → opens side panel
5. Go to Settings tab → enter your Signal API URL (e.g. `https://your-app.up.railway.app`)
6. Click "Test connection" → should show ✅
7. (Optional) Run `npm run chrome-data` in the project root to bake local intel data

## Architecture

```
sidepanel.html/js/css  — Main UI (3 tabs: Dashboard, Intel, Settings)
popup.html/js/css      — Slim quick-glance badge + "Open side panel" trigger
background.js          — Service worker (polling, notifications, context menu, side panel opener)
content.js             — Page text extraction with site-specific parsers
data/companies.json    — Pre-baked signal digest (generated by npm run chrome-data)
shared/
  api.js               — Fetch wrapper for Signal API (auto-prepends base URL)
  ai.js                — Chrome built-in AI (summarize, classify, intelCheck, rewrite)
  constants.js         — Storage keys, impact colors, signal types, utility functions
icons/                 — Extension icons (16/48/128px)
```

## Data Flow

```
┌─────────────────────────────────────────────────────────────┐
│ READING (Dashboard tab)                                      │
│   GET /api/signals → renders signal list                     │
│   GET /api/config  → company names, IDs                      │
│   GET /api/cron-status → last run time                       │
│   PATCH /api/signal → reclassify / dismiss to noise          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ WRITING (Intel tab)                                          │
│   POST /api/clip → save manual signal to Turso               │
│   Fields: competitorId, signalType, title, notes, link       │
│   sourceKind = 'manual-clip', classifyMethod = 'human'       │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ INTEL CHECK (Intel tab, step 1)                              │
│   Reads: data/companies.json (local) OR /api/signals (live)  │
│   Runs: Chrome Prompt API (LanguageModel) on-device          │
│   Compares: page text vs. pre-baked signal digest            │
│   Output: what's new / what you know / impact / clip?        │
└─────────────────────────────────────────────────────────────┘
```
